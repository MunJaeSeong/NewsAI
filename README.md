# 썸센스(Sumsens)

요약(summary)와 감정(sentiment) 그리고 뉴스(news)


## 💻 프로젝트 개요  
**"“한번에 알아보기 쉬운 뉴스블로그, 썸센스”" <br/>**

**썸센스**는 네이버 뉴스 API를 기반으로 뉴스를 제공합니다. <br/>
또한 뉴스를 부정적, 긍정적 요인을 분석허여 긍,부정적 내용의 뉴스를 각각 분리하여 볼 수 있습니다.  <br/>

---

##  🔮 기대 효과

**1. 편리성 향상**<br/>
원하는 뉴스들의 요약본을 한눈에 보기 편하며, 뉴스 기사의 성향이 긍정적인지 부정적인지 알아내기 쉬움.  <br/>
**3. 확장 가능성**<br/>
검색 속도 개선 <br/>
유사 검색어, AI기반 검색 추가 <br/>
